<p>
<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong><a href="https://github.com/JaukG9/mental-health-sentiment-analysis">Mental Health Sentiment Analysis</a></strong>: lightweight BERT-based and Random Forest pipeline for automated mental health text triage (about 85% accuracy), deployed on Hugging Face Spaces with a GitHub Pages frontend. Published in the <a href="https://doi.org/10.67149/yhjs2024.5/5wcbbc4m">International Journal of Secondary Computing and Applications Research</a>.<br>
<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong><a href="https://github.com/JaukG9/voice-health">Voice Health</a></strong> <em>(in progress)</em>: XGBoost model on the UCI Parkinson's voice dataset, with SHAP for interpreting vocal biomarkers. It grew out of a technical assessment for a university research lab application.<br>
<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong><a href="https://github.com/JaukG9/Parkinsons-Arduino">Parkinson's TinyWatch</a></strong>: an Arduino-based wearable for Parkinson's patients, built at Rice DHYS. It combines a pulse oximeter, an accelerometer and Bluetooth to track movement and vitals in real time and alert a caregiver when needed.<br>
<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong><a href="https://github.com/JaukG9/showdown-AI">Pokémon Showdown AI</a></strong> <em>(in progress)</em>: a supervised imitation-learning AI for competitive Pokémon Showdown (Gen 9 OU), built as a residual MLP trained on a 725-dimensional feature vector from my own gameplay data, collected through a terminal proxy bot using poke-env.<br>
<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong>AP Research</strong>: a quantitative study of implicit and adaptive video game tutorials in gamified education, comparing player performance and engagement across 6 conditions. The paper has been submitted to the International Journal of High School Research (IJHSR). The game I built for it is <a href="https://github.com/JaukG9/2DPlatformer-IAGE">IAGE 2D Platformer</a>.
</p>

<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong><a href="https://github.com/JaukG9/VEX-Template-285C">VEX V5 Template</a></strong>: a template for VEX V5 programming built on PROS and LemLib.<br>
<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong><a href="https://github.com/JaukG9/Pushback-285C">Pushback 285C</a></strong>: competition code for the Pushback season for 285C Discobots Chaos.<br>
<img src="./assets/headers/bullet.png" width="11"/>&nbsp; <strong><a href="https://github.com/JaukG9/Override-285C">Override 285C</a></strong>: competition code for the Override season for 285C Discobots Chaos.
</p>

Outside competition code, I designed automatic motion-chaining formulas for LemLib's `moveToPoint()` and `turnToHeading()`, using kinematic stopping distance and trapezoidal or triangular motion profiles so the robot carries its current speed into the next movement instead of stopping and restarting between points.
